# JinGleya Sans webfont

WOFF2 builds and specimen for **JinGleya Sans**, pairing Alegreya Sans Latin
with Tsanger JinKai 04 Chinese outlines at their original 100% size in Light,
Regular, and Bold weights, plus genuine Alegreya Sans Latin italics. Chinese
glyphs remain upright in italic styles.

[View the specimen](https://hanlhe.github.io/JinGleya-Sans-Webfonts/).

## Use

```html
<link rel="stylesheet" href="https://hanlhe.github.io/JinGleya-Sans-Webfonts/JinGleyaSans.css">
```

```css
body {
  font-family: "JinGleya Sans", sans-serif;
  font-weight: 400; /* Available weights: 300, 400, 700 */
  font-style: normal; /* use italic for the matching italic face */
}
```

Both `font-style: normal` and `font-style: italic` are available at weights
300, 400, and 700.

This is a personal font build. Tsanger JinKai 04 is limited to personal,
noncommercial use. The WOFF2 contains the upstream font notices in its metadata;
do not use this hosted font for commercial work.
