# JinGleya Sans webfont

WOFF2 build and specimen for **JinGleya Sans**, pairing Alegreya Sans Regular
Latin with Tsanger JinKai 04 W03 Chinese outlines at their original 100% size.

[View the specimen](https://hanlhe.github.io/JinGleya-Sans-Webfonts/).

## Use

```html
<link rel="stylesheet" href="https://hanlhe.github.io/JinGleya-Sans-Webfonts/JinGleyaSans.css">
```

```css
body {
  font-family: "JinGleya Sans", sans-serif;
  font-weight: 400;
}
```

This is a personal font build. Tsanger JinKai 04 is limited to personal,
noncommercial use. The WOFF2 contains the upstream font notices in its metadata;
do not use this hosted font for commercial work.

## Updates

The source fonts and build script are maintained in the private
[JinGleya Sans repository](https://github.com/hanlhe/JinGleya-Sans). This public
repository contains only the generated webfont, stylesheet, and specimen.
GitHub Pages publishes updates pushed to `main`.
